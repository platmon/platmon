# README screenshots

The repository README shows two pictures from this directory. Capture them on a real board with the
released package, not on a virtual machine, so the GPU, temperatures and power rails are there.

| File | What | How |
| --- | --- | --- |
| `screenshot-web.png` | the web page's Overview, dark theme, about 1280 × 800 | `http://<device>:9797` in a browser; crop to the page |
| `screenshot-cli.png` | the terminal client's Overview, about 100 × 30 characters | `platmon` in a dark terminal; a screenshot, not copied text |

Before committing: check that the host name and interface names in the picture are ones you are willing to
publish, and keep each file under about 300 kB.
